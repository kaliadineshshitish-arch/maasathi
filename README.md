# Maasathi — Pregnancy Tracker (PWA)

A privacy-first pregnancy tracker. **All data stays on the user's phone.**

**Live app:** https://kaliadineshshitish-arch.github.io/maasathi/

## Features
- **12 Indian languages** — English, हिन्दी, বাংলা, मराठी, தமிழ், తెలుగు, ગુજરાતી, ಕನ್ನಡ, മലയാളം, ਪੰਜਾਬੀ, ଓଡ଼ିଆ, اردو
- Week-by-week tracker (week, days left, baby size)
- Symptom log, weight log + graph, blood pressure log
- Kick counter, contraction timer, due date calculator
- Medicine + appointment reminders with acknowledgement (Taken / Skip / Snooze) and history
- Doctor report (PDF) for check-ups
- Appointments, hospital bag checklist, notes
- App lock (PIN) with AES-GCM 256-bit encryption
- DPDP Act 2023: consent, data export, one-click delete
- Offline-first PWA (installable, no ads, no trackers)

## Important
This app does **not** give medical advice, measure BP, or recommend medicine.
It is a personal tracking tool. Always consult a qualified doctor.

## Tech
Vanilla HTML/CSS/JS. No build step. No external trackers.
